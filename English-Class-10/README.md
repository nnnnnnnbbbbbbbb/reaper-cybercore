# Class 10 CBSE English — Revision Notes

This folder contains independently written revision notes for four prose lessons:

1. [The Sermon at Benares](The-Sermon-at-Benares.md)
2. [The Proposal](The-Proposal.md)
3. [Bholi](Bholi.md)
4. [The Book That Saved the Earth](The-Book-That-Saved-the-Earth.md)

These files are original summaries and exam revision aids, not scans or reproductions of NCERT textbook chapters.
